# PCL 下载限制解除 · 一键补丁

一个单文件 `.bat` 小工具：**把 `Plain Craft Launcher 2.exe` 拖进去，就能解除 PCL 内置的下载限制**（把"禁止第三方下载源/加载器"的那段逻辑改回来）。

不需要安装任何东西，不需要 .NET SDK，不需要反编译工具，只依赖 Windows 自带的 PowerShell。

```

  ================================================================
```

## 使用方法

下载 [`PCL一键补丁.bat`](./PCL一键补丁.bat)，随便放到哪里（桌面就行）。

| 场景 | 操作 |
| --- | --- |
| **最省事** | 把 `Plain Craft Launcher 2.exe` **直接拖到 bat 文件图标上** |
| **拖文件夹** | 把 PCL 所在的整个文件夹拖上去，它会自己进去找 exe |
| **双击运行** | 自动查找：本目录 → 上一级目录 → 桌面/下载；找到多个会列序号让你选 |
| **一次多个** | 可以同时拖多个 exe，逐个处理 |
| **还原** | 把同目录下的 `*.bak_时间戳` 备份文件拖回 bat 上即可 |

拖进去之后全程无交互。成功后结尾可以按：

- `R` —— 立刻用刚才的备份还原
- `L` —— 直接启动 PCL
- `回车` —— 退出

## 它做了什么

1. **分析**：把 exe 当程序集反射加载，找到 `PCL.PageDownloadInstall.LoaderInit` 方法，读出它的 IL 字节码。
2. **校验**：确认这段 IL 是预期的"关闭下载"版本（长度必须为 94 字节，并匹配固定特征字节）。**不匹配就拒绝修改**，不会瞎改不认识的版本。
3. **备份**：原地生成 `Plain Craft Launcher 2.exe.bak_yyyyMMdd_HHmmss`。
4. **修改**：把 `LoaderInit` 里"限制加载器"的分支替换成 `ldsfld PCL.ModDownload.DlClientListLoader`，即恢复成使用正常的下载加载器列表。
5. **校验**：重新读取文件、重新加载程序集，并用 `RuntimeHelpers.PrepareMethod` 强制 JIT 编译一遍被改过的方法——只有能正常编译才算成功，否则**自动回滚**。

任何一步出错都会自动还原，不会留下一个打不开的 exe。

## 适用范围

- ✅ **PCL 2.x 的 .NET 版** `Plain Craft Launcher 2.exe`（如 2.99.0.0）
- ❌ PCL CE / `PCL2_CE_Release_x64.exe` 等其它启动器 —— 代码结构不同，会明确报"版本暂不支持"
- ❌ 早期版本（如 2.13，`LoaderInit` 只有 62 字节）—— 同样是不同实现，工具会拒绝修改

只支持 Windows，需要 **Windows PowerShell 5.0+**（Windows 10 / 11 自带 5.1）。

## 还原方法

三种任选：

1. 打补丁成功后，在窗口里按 `R`；
2. 把 `Plain Craft Launcher 2.exe.bak_时间戳` 拖到 bat 上；
3. 手动把备份文件重命名回去覆盖 `Plain Craft Launcher 2.exe`。

PCL 自动更新/覆盖安装后，补丁会失效，重新拖一次即可。

## 常见问题

**Q：提示"写入失败，请先完全退出 PCL"？**
PCL 还在运行（包括托盘图标）。工具会先问你要不要自动关掉；如果你点了拒绝，就手动退出再重试。

**Q：提示"没有找到预期的'关闭下载'代码"？**
你的 exe 版本和工具支持的不一致（或者已经被别的工具改过）。工具不会强行修改，原文件保持不动。

**Q：会不会破坏 PCL 的其他功能？**
改动只涉及 `LoaderInit` 一个方法的几十个字节，其余内容原样保留。补丁后的方法会先经过 JIT 编译校验才会保留。

**Q：为什么 bat 里有一大段 PowerShell？**
为了单文件、免安装。bat 头部只负责把自身内部的 PowerShell 段切出来丢到 `%TEMP%` 执行；因为 bat 头部保持纯 ASCII，所以不会出现中文乱码。

**Q：杀毒软件报毒？**
脚本会读取并改写自身同目录的 exe，这类行为容易被启发式引擎误判。代码全部明文，可自行审阅。
